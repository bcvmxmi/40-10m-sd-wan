## 同样是10M，报价为什么能差出几倍

报价由七八个变量共同决定，逐个拆开看：

- **带宽**：计价核心。跨境带宽是稀缺资源，带宽翻倍，价格往往不止翻倍，10M和100M的年费可以差5-8倍。按业务峰值选带宽，别为闲置买单。
- **两端城市**：国内端在北上广深接入成本通常更低，二三线城市有附加费用；海外端到香港、新加坡、日本便宜，到欧美贵一档，到中东、非洲、南美最贵。同样10M，上海到香港和内陆城市到香港能差30%以上。
- **线路类型**：IEPL/IPLC点对点独享，品质最高也最贵；MPLS居中；SD-WAN借助公共网络做叠加优化，成本低30%-50%，代价是对极端稳定性的保障弱一些。
- **独享还是共享**：部分低价SD-WAN是共享资源，普通外贸办公够用；涉及核心业务系统、实时视频、海外直播、跨国ERP，就要盯住带宽保障和线路质量。
- **IP资源**：固定IP、独享IP、原生IP、住宅IP价格差别明显，跨境电商和海外社媒运营对IP纯净度敏感，这笔钱省不得。
- **节点和设备**：小团队用软件客户端接入，部署成本低；总部加多个分公司要部署多台CPE设备和节点，设备费、节点费、实施费都要算进去。
- **合约年限与SLA**：签1年单价高于3年长约，长期客户一般有10%-20%折扣，两种年限的单价能差15%-25%；承诺99.9%以上可用性、带故障赔付的高等级SLA更贵。对生产业务来说，SLA这笔钱不建议省。

## 报价单之外，预算里容易漏掉的四笔钱

按报价签合同只是预算的开始，这几笔钱经常在签完之后才冒出来：

1. **初装费和施工费**。绝大多数运营商按年起签，月付单价贵很多，而且通常收初装费；海外端节点越偏，施工周期和费用越难控制。
2. **设备押金和购置费**。企业级CPE路由器有的买断、有的收押金，行情可以参考悦播出海：CPE押金200元/台，退租且设备无损全额退还。
3. **IP和带宽升级费**。中途想加带宽、换独享IP，属于合同变更，一般按新配置重新计价，未必沿用老折扣。
4. **长约锁死的机会成本**。3年约单价便宜，但业务收缩时退租难，签约前想清楚未来三年的规模变化。

还有一笔隐形的：接入城市。办公室不在北上广深的，询价时主动说明，别等报价出来才发现多了附加费。

## 先想清楚：你的业务需要整条专线吗

不少询价的人最后发现自己根本不需要整条专线。判断标准看业务形态：

- **需要整条专线的**：跨国办公协同、ERP/OA系统跨境访问、分支机构组网、大规模数据同步。这些吃的是“传输通道”，办公室整体上网质量都靠它。
- **不需要整条专线的**：TikTok运营、直播带货、多店铺管理、海外社媒、广告投放验证。这些要的是海外IP和稳定的访问环境。IPIPGO这类服务商的TikTok专线开通即用、无需自建海外网络环境，专为直播和短视频场景优化，成本远低于运营商专线；静态住宅代理和动态住宅IP也能覆盖社媒运营、数据采集的需求，按用量付费——不过使用代理IP需要自备可用的海外网络环境（TikTok专线除外），这点容易被忽略。

更省钱的玩法是混合组网：核心业务系统走专线保稳定，日常运营和账号矩阵交给轻量方案，整体开支能降不少。

## 询价和签约的四步避坑清单

**第一步，把配置一次说清。**别只问“10M多少钱”，直接报：办公人数、接入城市、目标国家、带宽要求、业务类型、IP需求。信息给全，报价才有可比性，也能避免二次加价。

**第二步，核实资质。**确认服务商具备相应的电信业务经营许可，看清合同主体是谁，避免和中间转包方签约。跨境专线属企业电信业务，三大运营商办理时要提供营业执照等资质材料。

**第三步，SLA写进合同。**可用性承诺、故障响应时间、赔偿条款，全部落在纸面上，口头承诺不算数。

**第四步，先测后签。**要求开通测试期，在真实业务时段——尤其是晚高峰——实测延迟、丢包和抖动，达标再签长约。悦播出海这类支持3天免费测试的方案，测试成本几乎为零。

## 常见问题

**跨境专线最便宜一年要多少钱？**
轻量方案几百到几千元：OSDWAN办公版690元/年，悦播出海东南亚办公专线约5400元/年起。传统运营商专线10M一年也要2万元起步。

**个人可以办理跨境专线吗？**
三大运营商的跨境专线仅面向企业客户，要提供营业执照等资质。个人或小团队做TikTok运营、跨境电商，选TikTok专线、代理IP这类轻量方案即可。

**10M带宽到底够不够用？**
20人以内的日常办公、邮件和网页操作基本够用；有大量文件同步或视频会议，从50M起步。估算方法：人均0.5-1M，再留余量。直播推流一般要5M-10M以上的独享上行。

**专线价格还能谈吗？**
能。签约年限越长、带宽越大，折扣空间越高；同时向多家运营商和持牌服务商询价，同样的带宽和两端城市，报价可能差20%以上。

**办理专线要多久？**
常见周期2-6周，取决于两端城市资源。海外端节点越偏，开通越慢，谈合同时把施工周期和违约责任写清楚。
